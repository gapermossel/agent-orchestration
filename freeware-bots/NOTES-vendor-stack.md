# Vendored upstream sources (not included)

The bots are built against a local library of open-source projects held at pinned versions (about 1.7 GB, not published here). Point `library_src` in the config at your own copy. Contents of `src/`:

- ansible — automation/configuration management
- compose — Docker Compose
- discord.py — Discord bot library
- faster-whisper — fast speech-to-text
- kokoro — text-to-speech model
- langgraph — agent workflow graphs
- librechat — open-source chat UI
- llama.cpp — local LLM inference in C/C++
- matrix-nio — Matrix client library
- moby — Docker engine
- ollama — local model runner
- paddleocr — OCR toolkit
- podman — daemonless containers
- python-telegram-bot — Telegram bot library
- smolagents — small agent framework
- tesseract — OCR engine
- uptime-kuma — uptime monitoring
- vllm — high-throughput LLM serving
- whisper.cpp — speech-to-text in C/C++
